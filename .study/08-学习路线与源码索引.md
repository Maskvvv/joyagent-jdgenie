# 学习路线与源码索引

## 一、推荐学习路线

### 阶段一：了解项目（1-2天）

1. 阅读 [01-项目概览](01-项目概览.md)，了解项目定位和整体结构
2. 阅读 [06-配置与部署指南](06-配置与部署指南.md)，本地部署运行项目
3. 体验 Demo：尝试输入不同类型的 query，观察系统行为

### 阶段二：理解架构（3-5天）

1. 阅读 [02-智能体架构详解](02-智能体架构详解.md)，理解 Agent 继承体系
2. 重点阅读以下源码：
   - [BaseAgent.java](../genie-backend/src/main/java/com/jd/genie/agent/agent/BaseAgent.java) - 理解主循环
   - [ReActAgent.java](../genie-backend/src/main/java/com/jd/genie/agent/agent/ReActAgent.java) - 理解 think-act 模式
   - [PlanningAgent.java](../genie-backend/src/main/java/com/jd/genie/agent/agent/PlanningAgent.java) - 理解规划
   - [ExecutorAgent.java](../genie-backend/src/main/java/com/jd/genie/agent/agent/ExecutorAgent.java) - 理解执行
3. 阅读 [03-工具系统详解](03-工具系统详解.md)，理解工具机制

### 阶段三：深入核心（5-7天）

1. 阅读 [04-LLM调用与调度引擎](04-LLM调用与调度引擎.md)，理解 LLM 交互
2. 重点阅读以下源码：
   - [LLM.java](../genie-backend/src/main/java/com/jd/genie/agent/llm/LLM.java) - LLM 调用核心
   - [GenieController.java](../genie-backend/src/main/java/com/jd/genie/controller/GenieController.java) - 请求入口
   - [PlanSolveHandlerImpl.java](../genie-backend/src/main/java/com/jd/genie/service/impl/PlanSolveHandlerImpl.java) - 调度核心
3. 阅读 [05-核心流程源码走读](05-核心流程源码走读.md)，走读完整请求生命周期

### 阶段四：实践扩展（持续）

1. 阅读 [07-创新点与扩展开发](07-创新点与扩展开发.md)
2. 尝试添加自定义工具
3. 尝试修改提示词优化效果
4. 尝试接入不同的 LLM 模型

## 三、关键概念速查

| 概念 | 说明 |
|------|------|
| ReAct | Reasoning + Acting，思考-行动交替模式 |
| Plan & Solve | 先规划再执行的模式 |
| MCP | Model Context Protocol，模型上下文协议 |
| SSE | Server-Sent Events，服务端推送事件 |
| DGP | Data Governance Protocol，数据治理协议 |
| SOP | Standard Operating Procedure，标准操作流程 |
| Digital Employee | 数字员工，为工具分配人设 |
| Tool Evolution | 工具进化，自动拆解重组产生新工具 |
| TableRAG | 表格 RAG，两阶段动态选表选字段 |
| NL2SQL | Natural Language to SQL，自然语言转 SQL |
