# 核心流程源码走读

## 一、一次完整请求的生命周期

以用户输入"分析最近美元和黄金的走势"为例，走读完整流程。

### Step 1: 请求入口

**GenieController.AutoAgent()**

```java
@PostMapping("/AutoAgent")
public SseEmitter AutoAgent(@RequestBody AgentRequest request) {
    // 1. 创建 SSE 连接
    SseEmitter emitter = new SseEmitter(60 * 60 * 1000L);
    
    // 2. 启动心跳
    ScheduledFuture<?> heartbeatFuture = startHeartbeat(emitter, requestId);
    
    // 3. 拼接输出样式
    request.setQuery(handleOutputStyle(request));
    // query 变为: "分析最近美元和黄金的走势 以 html 展示"
    
    // 4. 异步执行
    ThreadUtil.execute(() -> {
        // 构建 AgentContext
        AgentContext agentContext = AgentContext.builder()
            .requestId(request.getRequestId())
            .query(request.getQuery())
            .printer(new SSEPrinter(emitter, request, request.getAgentType()))
            .build();
        
        // 构建工具列表
        agentContext.setToolCollection(buildToolCollection(agentContext, request));
        
        // 获取处理器并执行
        AgentHandlerService handler = agentHandlerFactory.getHandler(agentContext, request);
        handler.handle(agentContext, request);
        
        emitter.complete();
    });
    
    return emitter;
}
```

### Step 3: Plan & Solve 调度（假设 agentType=3）

**PlanSolveHandlerImpl.handle()**

```java
public String handle(AgentContext agentContext, AgentRequest request) {
    // 1. SOP 召回
    handleSopRecall(agentContext, request);
    
    // 2. 创建三个 Agent
    PlanningAgent planning = new PlanningAgent(agentContext);
    ExecutorAgent executor = new ExecutorAgent(agentContext);
    SummaryAgent summary = new SummaryAgent(agentContext);
    
    // 3. PlanningAgent 首次运行 - 拆解任务
    String planningResult = planning.run(agentContext.getQuery());
    // planningResult = "执行顺序1. 走势搜索: 搜索美元和黄金最近走势数据<sep>执行顺序2. 数据分析: 分析搜索数据提取关键指标<sep>执行顺序3. 报告生成: 生成网页版走势分析报告"
    
    // 4. 循环执行
    while (stepIdx <= maxStepNum) {
        List<String> planningResults = Arrays.stream(planningResult.split("<sep>"))
            .map(task -> "你的任务是：" + task)
            .collect(Collectors.toList());
        
        // 5. ExecutorAgent 执行子任务
        String executorResult = executor.run(planningResults.get(0));
        
        // 6. PlanningAgent 根据执行结果更新计划
        planningResult = planning.run(executorResult);
        
        // 7. 如果计划完成
        if ("finish".equals(planningResult)) {
            TaskSummaryResult result = summary.summaryTaskResult(
                executor.getMemory().getMessages(), request.getQuery());
            agentContext.getPrinter().send("result", taskResult);
            break;
        }
    }
}
```

### Step 4: PlanningAgent 的 think-act 循环

**PlanningAgent.think()**

```java
public boolean think() {
    // 1. 替换提示词中的占位符
    setSystemPrompt(getSystemPromptSnapshot()
        .replace("{{files}}", filesStr)
        .replace("{{query}}", "分析最近美元和黄金的走势 以 html 展示")
        .replace("{{date}}", "2026年4月13日"));
    
    // 2. 调用 LLM，携带 PlanningTool
    CompletableFuture<LLM.ToolCallResponse> future = getLlm().askTool(
        context,
        getMemory().getMessages(),
        Message.systemMessage(getSystemPrompt(), null),
        availableTools,  // 只有 PlanningTool
        ToolChoice.AUTO, null, context.getIsStream(), 300
    );
    
    // 3. LLM 返回工具调用 - 调用 planning 工具创建计划
    LLM.ToolCallResponse response = future.get();
    setToolCalls(response.getToolCalls());
}
```

## 二、关键设计模式总结

### 2.1 策略模式

Agent 类型路由使用策略模式：

```
AgentHandlerService (接口)
    ├── PlanSolveHandlerImpl  → agentType = 3
    └── ReactHandlerImpl     → agentType = 5
```

通过 `AgentHandlerFactory.getHandler()` 根据类型选择处理器。

### 2.2 模板方法模式

BaseAgent.run() 定义了算法骨架，子类通过实现 step() 来定制行为：

```java
// BaseAgent（模板方法）
public String run(String query) {
    while (currentStep < maxSteps && state != AgentState.FINISHED) {
        String stepResult = step();  // 子类实现
    }
}

// ReActAgent（模板方法）
public String step() {
    boolean shouldAct = think();  // 子类实现
    return act();                 // 子类实现
}
```

### 2.3 观察者模式

SSE 输出使用类似观察者的模式：

```
Agent → Printer.send(eventType, data) → SSEEmitter → 前端
```

### 2.4 工厂模式

AgentHandlerFactory 根据请求类型创建对应的 Handler。

## 三、数据流全景

```
前端 UI
  │ POST /AutoAgent
  ▼
GenieController
  │ 构建 AgentContext + ToolCollection
  ▼
AgentHandlerFactory
  │ 根据 agentType 选择 Handler
  ▼
┌─────────────────────────────────────────┐
│ PlanSolveHandlerImpl                     │
│                                          │
│  PlanningAgent ←→ LLM (PlanningTool)    │
│       │                                  │
│       ▼ 子任务                            │
│  ExecutorAgent ←→ LLM (All Tools)       │
│       │                                  │
│       ├── DeepSearchTool → genie-tool    │
│       ├── CodeInterpreterTool → genie-tool│
│       ├── ReportTool → genie-tool        │
│       ├── FileTool → genie-tool          │
│       └── McpTool → MCP Server           │
│                                          │
│  SummaryAgent ←→ LLM                     │
└─────────────────────────────────────────┘
  │ SSE events
  ▼
前端 UI（实时展示）
```
