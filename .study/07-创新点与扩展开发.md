# 创新点与扩展开发

## 一、核心创新点

### 1.1 Multi-level & Multi-pattern Thinking

JoyAgent-JDGenie 最大的创新之一是**多层级、多模式思考**机制：

- **Multi-level**: 分为 work level（整体任务级别）和 task level（子任务级别）
- **Multi-pattern**: 结合 Plan & Executor 模式和 ReAct 模式

```
Work Level (PlanningAgent)
  │ 拆解任务
  ├── Task Level 1 (ExecutorAgent) → ReAct 循环
  ├── Task Level 2 (ExecutorAgent) → ReAct 循环
  └── Task Level 3 (ExecutorAgent) → ReAct 循环
```

这种设计使得系统既能处理需要全局规划复杂任务，又能在每个子任务中灵活应对。

### 1.2 Cross Task Workflow Memory

跨任务级别的相似任务记忆机制。当遇到与历史任务相似的新任务时，系统可以复用之前的执行经验，提高效率。

### 1.3 Tool Evolution via Auto-disassembly-and-reassembly

**工具进化机制**——基于已有工具自动拆解和重组产生新工具：

1. 不是从零开始生成新工具（减少错误工具的生成）
2. 基于已有工具**隐性拆解**为原子工具
3. 基于原子工具结合大模型**自动组合**成新工具
4. 不需要人力预先定义和拆解原子工具

### 1.4 数字员工（Digital Employee）

为每个工具动态分配"人设"，使 LLM 更自然地决定何时使用哪个工具：

```json
{
    "file_tool": "市场洞察专员",
    "deep_search": "信息检索专家",
    "code_interpreter": "数据计算专家",
    "report_tool": "报告撰写师"
}
```

### 1.5 SOP Plan 模式

在 Plan & Solve 模式基础上，支持用户预定义分析流程（SOP），升级为 SOPPlan 模式：

- 用户可以定义标准操作流程
- 系统基于 SOP 进行任务规划和执行
- 特别适合企业内部标准化分析场景

## 二、扩展开发指南

### 2.1 添加自定义子 Agent

#### 步骤一：实现 BaseTool 接口

```java
package com.jd.genie.agent.tool.common;

import com.jd.genie.agent.agent.AgentContext;
import com.jd.genie.agent.tool.BaseTool;
import java.util.Map;

public class WeatherTool implements BaseTool {
    private AgentContext agentContext;
    
    public void setAgentContext(AgentContext context) {
        this.agentContext = context;
    }
    
    @Override
    public String getName() {
        return "agent_weather";
    }
    
    @Override
    public String getDescription() {
        return "这是一个可以查询天气的智能体，输入地点即可获取天气信息";
    }
    
    @Override
    public Map<String, Object> toParams() {
        return Map.of(
            "type", "object",
            "properties", Map.of(
                "location", Map.of(
                    "description", "查询天气的地点",
                    "type", "string"
                )
            ),
            "required", List.of("location")
        );
    }
    
    @Override
    public Object execute(Object input) {
        // 解析参数
        Map<String, Object> params = (Map<String, Object>) input;
        String location = (String) params.get("location");
        
        // 调用天气 API
        String weatherInfo = callWeatherApi(location);
        
        // 通知前端
        agentContext.getPrinter().send("tool_result", 
            AgentResponse.ToolResult.builder()
                .toolName(getName())
                .toolParam(params)
                .toolResult(weatherInfo)
                .build(), null);
        
        return weatherInfo;
    }
    
    private String callWeatherApi(String location) {
        // 实际调用天气 API
        return location + " 今日天气晴朗，温度 25°C";
    }
}
```

#### 步骤二：注册工具

在 `GenieController.buildToolCollection()` 中添加：

```java
WeatherTool weatherTool = new WeatherTool();
weatherTool.setAgentContext(agentContext);
toolCollection.addTool(weatherTool);
```

#### 步骤三：更新提示词

在 `application.yml` 的 executor/react system_prompt 中添加工具使用说明。

### 2.2 添加 MCP 工具

MCP 工具无需修改 Java 代码，只需：

1. 启动一个 MCP 兼容的服务
2. 在 `application.yml` 中添加 MCP Server URL
3. 系统自动发现并注册工具

#### MCP Server 示例（Python）

```python
from mcp.server.fastmcp import FastMCP

mcp = FastMCP("weather-server")

@mcp.tool()
def get_weather(location: str) -> str:
    """查询指定地点的天气"""
    return f"{location} 今日天气晴朗，温度 25°C"

@mcp.tool()
def get_forecast(location: str, days: int = 3) -> str:
    """查询未来几天的天气预报"""
    return f"{location} 未来{days}天天气晴朗"

mcp.run(transport="sse")
```

### 2.3 自定义 Agent 模式

如果需要全新的 Agent 模式（不同于 ReAct 和 Plan & Solve）：

1. 继承 `BaseAgent` 或 `ReActAgent`
2. 实现 `step()` 或 `think()` + `act()`
3. 实现 `AgentHandlerService` 接口
4. 在 `AgentHandlerFactory` 中注册

```java
@Component
public class CustomHandlerImpl implements AgentHandlerService {
    @Override
    public String handle(AgentContext agentContext, AgentRequest request) {
        CustomAgent agent = new CustomAgent(agentContext);
        agent.run(request.getQuery());
        // ...
    }
    
    @Override
    public Boolean support(AgentContext agentContext, AgentRequest request) {
        return AgentType.CUSTOM.getValue().equals(request.getAgentType());
    }
}
```

### 2.4 自定义提示词

所有提示词都在 `application.yml` 中配置，支持多版本：

```yaml
autobots:
  autoagent:
    executor:
      system_prompt: '{
        "default": "默认提示词...",
        "finance": "金融场景专用提示词...",
        "legal": "法律场景专用提示词..."
      }'
```

在代码中通过 key 选择：

```java
setSystemPrompt(genieConfig.getExecutorSystemPromptMap()
    .getOrDefault("finance", ToolCallPrompt.SYSTEM_PROMPT));
```

### 2.5 自定义 LLM 模型

在 `application.yml` 中添加新模型配置：

```yaml
llm:
  settings: '{
    "my-custom-model": {
        "model": "my-model-name",
        "max_tokens": 8192,
        "temperature": 0,
        "base_url": "https://my-llm-server.com",
        "apikey": "sk-xxx",
        "interface_url": "/v1/chat/completions",
        "max_input_tokens": 128000,
        "function_call_type": "function_call"
    }
  }'
```

然后在 Agent 配置中指定：

```yaml
autobots:
  autoagent:
    planner:
      model_name: my-custom-model
    executor:
      model_name: my-custom-model
```

## 三、genie-tool 工具扩展

### 3.1 添加新的 Python 工具

1. 在 `genie-tool/genie_tool/tool/` 下创建工具模块
2. 在 `genie-tool/genie_tool/prompt/` 下添加提示词模板
3. 在 `genie-tool/genie_tool/api/tool.py` 中注册 API 端点
4. 在后端创建对应的 BaseTool 实现来调用

### 3.2 工具模板结构

```python
# genie_tool/tool/my_tool.py
class MyTool:
    def __init__(self):
        pass
    
    async def run(self, query: str, **kwargs):
        # 工具逻辑
        result = await self._process(query)
        return result
    
    async def _process(self, query: str):
        # 具体处理逻辑
        pass
```

```python
# genie_tool/api/tool.py 中添加
@router.post("/my_tool")
async def post_my_tool(body: MyToolRequest):
    my_tool = MyTool()
    result = await my_tool.run(body.query)
    return {"code": 200, "data": result}
```

## 四、架构优势总结

| 优势 | 说明 |
|------|------|
| 可插拔工具 | BaseTool + MCP 双轨制，灵活扩展 |
| 多模型支持 | 不同 Agent 可用不同模型，成本优化 |
| 提示词外置 | 所有提示词在配置文件中，无需改代码 |
| 流式输出 | 全链路 SSE 流式，用户体验好 |
| 并发执行 | 子任务和工具调用支持并发 |
| 轻量部署 | 不依赖外部平台，Docker 一键启动 |
