# 工具系统详解

## 一、工具体系概览

JoyAgent-JDGenie 的工具系统采用**可插拔设计**，分为两大类：

1. **BaseTool（内置工具）**: Java 实现，直接在 JVM 中执行
2. **McpTool（MCP 工具）**: 通过 MCP 协议调用外部服务

所有工具统一由 `ToolCollection` 管理。

## 二、BaseTool 接口

**源码位置**: [BaseTool.java](../genie-backend/src/main/java/com/jd/genie/agent/tool/BaseTool.java)

```java
public interface BaseTool {
    String getName();              // 工具名称
    String getDescription();       // 工具描述
    Map<String, Object> toParams(); // 工具参数（JSON Schema 格式）
    Object execute(Object input);   // 执行工具
}
```

这是最简单的工具接口，只需实现四个方法即可定义一个新工具。

## 三、ToolCollection - 工具集合

**源码位置**: [ToolCollection.java](../genie-backend/src/main/java/com/jd/genie/agent/tool/ToolCollection.java)

ToolCollection 是工具的容器和调度器：

```java
public class ToolCollection {
    private Map<String, BaseTool> toolMap;        // 内置工具映射
    private Map<String, McpToolInfo> mcpToolMap;  // MCP 工具映射
    private JSONObject digitalEmployees;           // 数字员工配置
    private String currentTask;                    // 当前任务
    
    // 添加/获取/执行工具
    public void addTool(BaseTool tool);
    public void addMcpTool(String name, String desc, String parameters, String mcpServerUrl);
    public Object execute(String name, Object toolInput);
}
```

### 工具执行逻辑

```java
public Object execute(String name, Object toolInput) {
    if (toolMap.containsKey(name)) {
        // 内置工具：直接在 JVM 中执行
        return getTool(name).execute(toolInput);
    } else if (mcpToolMap.containsKey(name)) {
        // MCP 工具：通过 HTTP/SSE 调用外部服务
        return mcpTool.callTool(toolInfo.getMcpServerUrl(), name, toolInput);
    }
}
```

## 四、内置工具详解

### 4.1 PlanningTool - 计划工具

**源码位置**: [PlanningTool.java](../genie-backend/src/main/java/com/jd/genie/agent/tool/common/PlanningTool.java)

PlanningAgent 专用的内部工具，用于创建和管理任务计划。

**支持的命令**:
- `create`: 创建任务计划，包含步骤列表
- `mark_step`: 标记步骤状态
- `finish`: 标记任务完成

### 4.2 CodeInterpreterTool - 代码解释器

**源码位置**: [CodeInterpreterTool.java](../genie-backend/src/main/java/com/jd/genie/agent/tool/common/CodeInterpreterTool.java)

允许 Agent 编写和执行 Python 代码，用于数据处理、计算等任务。

**工作流程**:
1. Agent 生成 Python 代码
2. 后端将代码发送给 genie-tool 的 `/code_interpreter` 接口
3. genie-tool 在沙箱中执行代码
4. 返回执行结果和生成的文件

**使用约束**:
- 严禁处理纯文本文件（.txt, .md, .html）
- 严禁从非表格文件中提取表格
- 支持 .xlsx、.csv 等 Excel 表格文件

### 4.3 DeepSearchTool - 深度搜索

**源码位置**: [DeepSearchTool.java](../genie-backend/src/main/java/com/jd/genie/agent/tool/common/DeepSearchTool.java)

多轮深度搜索工具，支持多搜索引擎。

**工作流程**:
1. Agent 发起搜索请求
2. 后端调用 genie-tool 的 `/deepsearch` 接口
3. genie-tool 执行多轮搜索和推理
4. 返回搜索结果

### 4.4 ReportTool - 报告生成

**源码位置**: [ReportTool.java](../genie-backend/src/main/java/com/jd/genie/agent/tool/common/ReportTool.java)

生成 HTML/PPT/Markdown 格式的报告。

**工作流程**:
1. Agent 传入任务描述和相关文件
2. 后端调用 genie-tool 的 `/report` 接口
3. genie-tool 使用 LLM 生成报告内容
4. 返回报告文件信息

### 4.5 FileTool - 文件工具

**源码位置**: [FileTool.java](../genie-backend/src/main/java/com/jd/genie/agent/tool/common/FileTool.java)

文件管理工具，支持文件的读取、保存和管理。

### 4.6 DataAnalysisTool - 数据分析

**源码位置**: [DataAnalysisTool.java](../genie-backend/src/main/java/com/jd/genie/agent/tool/common/DataAnalysisTool.java)

数据分析工具，用于 DataAgent 场景下的智能问数和诊断分析。

## 五、MCP 工具系统

### 5.1 MCP 协议简介

MCP（Model Context Protocol）是一个标准化的协议，允许 AI 模型与外部工具和服务交互。JoyAgent-JDGenie 通过 genie-client 模块实现 MCP 客户端功能。

### 5.2 MCP 工具注册流程

```
1. GenieController.buildToolCollection() 启动时
2. 遍历配置中的 mcp_server_url 列表
3. 对每个 MCP Server 调用 listTool() 获取工具列表
4. 将工具信息（名称、描述、参数 Schema）注册到 ToolCollection
```

### 5.3 MCP 工具调用流程

```
1. LLM 决定调用某个 MCP 工具
2. ToolCollection.execute() 识别为 MCP 工具
3. McpTool.callTool() 通过 SSE 连接 MCP Server
4. MCP Server 执行工具并返回结果
5. 结果返回给 Agent
```

### 5.4 配置 MCP Server

在 `application.yml` 中添加：

```yaml
mcp_server_url: "http://ip1:port1/sse,http://ip2:port2/sse"
```

## 六、genie-tool 工具服务

**源码位置**: [genie-tool/](../genie-tool/)

genie-tool 是一个 Python FastAPI 服务，提供所有工具的实际执行能力。

### 目录结构

```
genie-tool/
├── genie_tool/
│   ├── api/
│   │   ├── tool.py           # 工具 API 路由
│   │   └── file_manage.py    # 文件管理 API
│   ├── tool/
│   │   ├── code_interpreter.py  # 代码解释器
│   │   ├── report.py            # 报告生成
│   │   ├── deepsearch.py        # 深度搜索
│   │   ├── auto_analysis.py     # 自动分析
│   │   ├── nl2sql.py            # 自然语言转 SQL
│   │   ├── plan_sop.py          # SOP 计划
│   │   ├── analysis_component/  # 分析组件
│   │   ├── search_component/    # 搜索组件
│   │   └── table_rag/           # 表格 RAG
│   ├── prompt/                   # 各工具的提示词模板
│   ├── model/                    # 数据模型
│   ├── db/                       # 数据库操作
│   └── util/                     # 工具函数
├── server.py                     # 服务入口
└── pyproject.toml                # Python 项目配置
```

### API 端点

| 端点 | 说明 |
|------|------|
| POST /code_interpreter | 代码解释器 |
| POST /report | 报告生成 |
| POST /deepsearch | 深度搜索 |
| POST /table_rag | 表格 RAG |
| POST /cal_engine | 计算引擎 |
| POST /auto_analysis | 自动分析 |
| POST /nl2sql | 自然语言转 SQL |
| POST /sopRecall | SOP 召回 |

### 流式输出

所有工具 API 都支持 SSE 流式输出，通过 `stream_mode` 参数控制：

- `general`: 逐条输出
- `token`: 按 token 数量批量输出
- `time`: 按时间间隔批量输出

## 七、如何添加自定义工具

### 方式一：添加内置工具（Java）

1. 实现 `BaseTool` 接口：

```java
public class WeatherTool implements BaseTool {
    @Override
    public String getName() { return "agent_weather"; }
    
    @Override
    public String getDescription() { return "查询天气的智能体"; }
    
    @Override
    public Map<String, Object> toParams() {
        return Map.of("type", "object",
            "properties", Map.of("location", Map.of("description", "地点", "type", "string")),
            "required", List.of("location"));
    }
    
    @Override
    public Object execute(Object input) { return "今日天气晴朗"; }
}
```

2. 在 `GenieController.buildToolCollection()` 中注册：

```java
WeatherTool weatherTool = new WeatherTool();
toolCollection.addTool(weatherTool);
```

### 方式二：添加 MCP 工具

1. 启动一个 MCP Server（可使用任何 MCP 兼容的服务）
2. 在 `application.yml` 中添加 MCP Server URL
3. 系统会自动发现并注册该 Server 上的所有工具
