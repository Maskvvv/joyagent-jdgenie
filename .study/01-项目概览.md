# JoyAgent-JDGenie 项目概览

## 一、项目简介

JoyAgent-JDGenie 是由京东开源的**业界首个开源高完成度轻量化通用多智能体产品**，定位为解决"快速构建多智能体产品的最后一公里问题"。

与当前市面上大多数只提供 SDK 或框架的开源 Agent 项目不同，JoyAgent-JDGenie 是一个**端到端完整的多智能体产品**，用户输入 query 后可直接获得回答或解决方案。例如用户输入"给我做一个最近美元和黄金的走势分析"，系统可以直接输出网页版或 PPT 版报告。

### 核心亮点

| 特性 | 说明 |
|------|------|
| 端到端完整产品 | 开箱即用，无需二次开发即可使用 |
| 轻量化 | 不依赖阿里云百炼、火山引擎等外部平台 |
| 多智能体框架 | 通用框架，新场景只需挂载子智能体或工具 |
| GAIA 榜单验证 | Validation 集 75.15%、Test 集 65.12%，超越 OWL、Smolagent 等 |
| 完整开源 | 前端、后端、框架、引擎、核心子智能体全部开源 |

## 二、项目模块结构

```
joyagent-jdgenie/
├── genie-backend/        # 后端服务（Java / Spring Boot）
├── genie-client/         # MCP 客户端（Python / FastAPI）
├── genie-tool/           # 工具服务（Python / FastAPI）
├── docs/                 # 文档与图片资源
├── Dockerfile            # Docker 部署配置
└── Genie_start.sh        # 一键启动脚本
```

### 2.1 genie-backend（后端核心）

- **技术栈**: Java 17 + Spring Boot 3.2.2 + MyBatis-Plus + H2
- **职责**: 智能体调度引擎、Agent 模式管理、LLM 调用、SSE 流式输出
- **端口**: 8080

### 2.2 genie-tool（工具服务）

- **技术栈**: Python 3.11 + FastAPI + uv
- **职责**: 提供各类工具的执行能力（代码解释器、报告生成、深度搜索、数据分析、NL2SQL 等）
- **端口**: 1601

### 2.3 genie-client（MCP 客户端）

- **技术栈**: Python 3.10+ + FastAPI + MCP SDK
- **职责**: MCP（Model Context Protocol）客户端，连接外部 MCP Server 获取工具列表并调用
- **端口**: 由配置决定

## 三、三大核心能力

### 3.1 通用多智能体（主分支）

核心的多 Agent 框架，支持 ReAct 和 Plan & Executor 两种智能体设计模式。

### 3.2 JoyDataAgent（data_agent 分支）

面向结构化表格数据的智能体，包含：
- **DGP 协议**: 数据治理协议与工具
- **智能问数**: 自然语言转 SQL 查询
- **诊断分析**: 趋势/周期/异常/相关性/因果归因
- **工作建议**: 基于分析结果提供建议

在 BirdSQL 公开榜单 Test 集准确率 **75.74%**，排名第4。

### 3.3 多模态知识管理（mrag 分支）

面向多模态非结构化知识的 RAG 解决方案：
- 集成 MinerU 解析框架
- 支持关键词、向量、知识图谱多策略融合检索
- 在 DoubleBench 数据集上正确率达 **76.2%**

## 五、快速部署

### 方式一：Docker 一键启动

```bash
git clone https://github.com/jd-opensource/joyagent-jdgenie.git
# 修改 application.yml 中的 LLM 配置
# 修改 genie-tool/.env_template 中的 API Key
docker build -t genie:latest .
docker run -d -p 3000:3000 -p 8080:8080 -p 1601:1601 --name genie-app genie:latest
# 访问 localhost:3000
```

### 方式二：手动启动

1. 启动前端: `cd ui && sh start.sh`
2. 启动后端: `cd genie-backend && sh build.sh && sh start.sh`
3. 启动工具服务: `cd genie-tool && uv sync && uv run python server.py`
4. 启动 MCP 客户端: `cd genie-client && sh start.sh`

### 环境要求

- JDK 17+
- Python 3.11
- pnpm 7+
- 需要配置 LLM API Key（支持 OpenAI 兼容接口，推荐 DeepSeek）
