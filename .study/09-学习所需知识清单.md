## 五、项目特有的设计思想

### 5.1 Agent 调度引擎

理解项目的核心调度逻辑是深入学习的关键：

```
GenieController（入口）
    │
    ├─→ AgentHandlerFactory（路由）
    │       │
    │       ├─→ PlanSolveHandlerImpl（Plan & Solve 模式）
    │       │       ├─→ PlanningAgent（任务规划）
    │       │       ├─→ ExecutorAgent（任务执行，循环每个子任务）
    │       │       └─→ SummaryAgent（任务总结）
    │       │
    │       └─→ ReactHandlerImpl（ReAct 模式）
    │               └─→ ReactImplAgent（思考-行动-观察循环）
    │
    └─→ SSE 流式输出（SseEmitterUTF8）
```

### 5.2 工具调用链路

```
Agent.think() → LLM.askTool() → OpenAI API → ToolCall 响应
    → Agent.act() → ToolCollection.execute() → BaseTool.execute()
        → HTTP 调用 genie-tool → Python 工具执行 → 结果返回
```

### 5.3 Prompt 模板系统

项目使用 `{{variable}}` 模板变量来动态注入上下文：
- `{{date}}` — 当前日期
- `{{files}}` — 可用文件列表
- `{{query}}` — 用户原始任务
- `{{sopPrompt}}` — SOP 提示词
- `{{history_dialogue}}` — 历史对话
