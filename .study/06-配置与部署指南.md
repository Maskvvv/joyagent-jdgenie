# 配置与部署指南

## 一、配置文件体系

### 1.1 后端配置 (application.yml)

**位置**: `genie-backend/src/main/resources/application.yml`

#### LLM 配置

```yaml
llm:
  default:
    base_url: 'https://api.openai.com'     # LLM API 地址
    apikey: 'sk-xxx'                        # API Key
    interface_url: '/chat/completions'       # 接口路径
    model: gpt-4.1                          # 默认模型
    max_tokens: 16384                       # 最大输出 token
  settings: '{
    "claude-3-7-sonnet-v1": {              # 可配置多个模型
        "model": "claude-3-7-sonnet-v1",
        "max_tokens": 8192,
        "temperature": 0,
        "base_url": "...",
        "apikey": "...",
        "max_input_tokens": 128000
    }
  }'
```

#### Agent 模型配置

不同 Agent 可以使用不同的模型：

```yaml
autobots:
  autoagent:
    planner:
      model_name: gpt-4.1          # 规划 Agent 使用的模型
      max_steps: 40                # 最大规划步数
      close_update: 1              # 关闭动态更新 Plan
    executor:
      model_name: gpt-4.1          # 执行 Agent 使用的模型
      max_steps: 40                # 最大执行步数
      max_observe: 10000           # 工具结果最大观察长度
    react:
      model_name: gpt-4.1          # ReAct Agent 使用的模型
      max_steps: 40                # 最大步数
```

#### MCP Server 配置

```yaml
mcp_server_url: "http://ip1:port1/sse,http://ip2:port2/sse"
```

#### 提示词配置

所有提示词都在 application.yml 中配置，支持多版本：

```yaml
autobots:
  autoagent:
    planner:
      system_prompt: '{"default": "...", "version2": "..."}'
      next_step_prompt: '{"default": "..."}'
    executor:
      system_prompt: '{"default": "..."}'
      next_step_prompt: '{"default": "..."}'
    react:
      system_prompt: '{"default": "..."}'
      next_step_prompt: '{"default": "..."}'
```

提示词中的占位符：

| 占位符 | 说明 |
|--------|------|
| {{tools}} | 工具描述列表 |
| {{query}} | 用户原始查询 |
| {{date}} | 当前日期信息 |
| {{files}} | 可用文件列表 |
| {{sopPrompt}} | SOP 提示词 |
| {{basePrompt}} | 基础提示词 |
| {{executorSopPrompt}} | 执行器 SOP 提示词 |
| {{history_dialogue}} | 历史对话信息 |

### 1.2 工具服务配置 (.env)

**位置**: `genie-tool/.env_template` → 复制为 `.env`

```bash
OPENAI_API_KEY=sk-xxx                    # LLM API Key
OPENAI_BASE_URL=https://api.openai.com   # LLM API 地址
DEFAULT_MODEL=gpt-4.1                    # 默认模型
SERPER_SEARCH_API_KEY=xxx                # Serper 搜索 API Key
FILE_SERVER_URL=http://localhost:1601     # 文件服务地址
```

### 1.3 前端配置

**位置**: `ui/.env`

可修改前端请求后端的路径。

## 二、数据库

项目使用 H2 内存数据库，初始化脚本：

- `genie-backend/src/main/resources/db/schema.sql` - 表结构
- `genie-backend/src/main/resources/db/data.sql` - 初始数据

H2 控制台访问：`http://localhost:8080/h2-console`

## 三、部署方式

### 3.1 Docker 部署（推荐）

```bash
# 1. 克隆项目
git clone https://github.com/jd-opensource/joyagent-jdgenie.git

# 2. 修改配置
# 编辑 genie-backend/src/main/resources/application.yml
# 编辑 genie-tool/.env_template → .env

# 3. 构建镜像
docker build -t genie:latest .

# 4. 启动容器
docker run -d -p 3000:3000 -p 8080:8080 -p 1601:1601 --name genie-app genie:latest

# 5. 访问
# http://localhost:3000
```

### 3.2 手动部署

#### 前置条件

- JDK 17+
- Python 3.11+
- pnpm 7+

#### Step 1: 启动前端

```bash
cd ui
sh start.sh
# 出现 Local: http://localhost:3000/ 即成功
```

#### Step 2: 启动后端

```bash
cd genie-backend
sh build.sh    # 编译
sh start.sh    # 启动
# 可通过 tail -f genie-backend_startup.log 观察日志
```

#### Step 3: 启动工具服务

```bash
cd genie-tool
pip install uv
uv sync
source .venv/bin/activate

# 首次启动需初始化数据库
python -m genie_tool.db.db_engine

# 配置环境变量
cp .env_template .env
# 编辑 .env 文件

# 启动服务
uv run python server.py
```

#### Step 4: 启动 MCP 客户端

```bash
cd genie-client
uv venv
source .venv/bin/activate
sh start.sh
```

### 3.3 一键启动

```bash
sh check_dep_port.sh   # 检查依赖和端口
sh Genie_start.sh      # 一键启动所有服务
```

## 四、使用 DeepSeek 模型

DeepSeek 是推荐的低成本方案：

### 后端配置

```yaml
llm:
  default:
    base_url: 'https://api.deepseek.com'
    apikey: 'sk-xxx'
    model: deepseek-chat
    max_tokens: 8192    # deepseek-chat 最大 8192
```

### 工具服务配置

```bash
DEEPSEEK_API_KEY=sk-xxx
DEEPSEEK_API_BASE=https://api.deepseek.com
DEFAULT_MODEL=deepseek/deepseek-chat
# 所有 ${DEFAULT_MODEL} 都改成 deepseek/deepseek-chat
```

## 六、常见问题

### Q1: 后端启动报 LLM 连接错误
检查 application.yml 中的 base_url 和 apikey 配置是否正确。

### Q2: 工具服务启动报 Serper API 错误
需要在 .env 中配置 SERPER_SEARCH_API_KEY，申请地址：https://serper.dev/

### Q3: 前端无法连接后端
检查 ui/.env 中的后端地址配置，确保与后端端口一致。

### Q4: Docker 部署后功能异常
确保容器内所有服务正常启动，检查日志：`docker logs genie-app`
